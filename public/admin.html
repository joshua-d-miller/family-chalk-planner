On your network

Turns on passkeys (Face ID, Touch ID, fingerprint) and is used in invite links. You’re on right now. A wrong address can’t lock you out: password + code works at any address.

⚠ With just a password, any device on your network — including smart plugs, TVs and anything on another VLAN that can reach the board — can sign in to the board with a password alone. It only applies when the board is opened by its IP address (like http://192.168.1.20:3002), never through your https:// address, and the admin console still asks for the code.

Updates

Every update backs up the board’s database first. If the new version doesn’t start properly, the board goes back to the version it had, with its database from before.

Saving restarts the board (a few seconds); screens reconnect by themselves. Everything here is kept in the board’s database; passwords, the calendar account, the album link and calendar links are stored encrypted. Passwords are never shown again.
